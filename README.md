# 반딧불 우체부

밤숲에서 토끼 토리와 고슴도치 밤이가 랜턴 하나를 나눠 들고 편지를 배달하는 2인 협동 3D 게임이에요.

## 플레이 방법

- **한 키보드로 같이하기**: 토리는 WASD + E, 밤이는 방향키 + Enter
- **온라인**: 한 사람이 "온라인 방 만들기"를 누르고 초대 링크(또는 4글자 방 코드)를 보내면, 다른 사람이 자기 기기에서 "방 참가하기"로 들어와요. 각자 WASD/방향키로 움직이고 E·Enter·Space로 행동해요. 휴대폰에서는 화면 조이스틱과 행동 버튼이 나와요.

## 구조

- `index.html` 한 파일로 된 정적 사이트예요. Three.js와 PeerJS를 jsDelivr CDN에서 불러와요.
- 온라인 플레이는 PeerJS 공개 중계 서버로 서로를 찾은 뒤 WebRTC로 두 브라우저를 직접 연결해요. 방을 만든 쪽이 게임을 계산하고, 참가한 쪽은 입력을 보내고 화면 상태를 받아요.
- 빌드 과정이 없어서 Vercel에서 Framework Preset을 "Other"로 두고 그대로 배포하면 돼요.

# 꼬마 빵집 (`/bakery`)

숲속 동물 손님에게 빵을 구워 팔고, 번 동전으로 마을을 꾸미는 1인용 3D 힐링 게임이에요. 배포 주소 뒤에 `/bakery`를 붙이면 열려요.

- **플레이**: 손님 머리 위 주문을 보고 🔥오븐에서 굽기(타이밍 게임) → 🎨장식대에서 토핑 → 카운터에서 건네기. 단골이 되면 선물을 주고, 더 친해지면 마을로 이사 와요.
- **조작**: PC는 WASD/방향키 + E/스페이스, 휴대폰은 화면 조이스틱과 행동 버튼. 두 손가락으로 확대/축소.
- **저장·이웃**: Supabase 로그인(이메일+비밀번호)으로 계정마다 마을이 저장되고, 🏡이웃 메뉴에서 다른 사람 마을에 놀러 가 하트와 방명록을 남길 수 있어요. DB 구성은 `bakery/supabase-setup.sql`에 있어요.
- 앱을 전환하거나 화면을 끄면 즉시 저장하고, 기기에도 사본을 남겨서 다음에 더 최신 쪽을 불러와요.
